O que é o Kadron Finance?

O Kadron Finance é um sistema SaaS de controle financeiro projetado com a estética premium característica do ecossistema Kadron (tons escuros e detalhes em vermelho vibrante), inspirado nas interfaces da Stripe e Linear. O objetivo é fornecer uma visão limpa, analítica e de alta fidelidade das movimentações financeiras pessoais e corporativas.

O sistema foi construído sobre o Next.js 15, garantindo tempos de resposta instantâneos via Server Components e otimizações automáticas de carregamento.

Recursos em Destaque

  • Context Switcher Inteligente: Alternância instantânea no topo do painel entre o contexto Pessoal e o Corporativo, carregando dados diferentes sem recarregar a página.
  • Gráficos de Alta Fidelidade: Visualização interativa de fluxo de caixa, despesas por categoria e evolução patrimonial utilizando Recharts.
  • Geração de PDF integrada: Criação sob demanda de relatórios mensais formatados e profissionais para download com um clique utilizando React-PDF.
  • Acompanhamento de Metas: Barras de progresso dinâmicas que comparam o faturamento e os investimentos atuais com metas pré-definidas.

Como Executar Localmente

Você pode rodar a aplicação em seu ambiente local com as seguintes instruções:

1. Instalar as dependências:

cd kadron-finance npm install

2. Configuração de Variáveis do Supabase:

Crie um arquivo `.env.local` na pasta raiz e adicione suas chaves:

NEXT_PUBLIC_SUPABASE_URL=sua_url_do_supabase NEXT_PUBLIC_SUPABASE_ANON_KEY=sua_chave_anonima

3. Executar o Servidor de Desenvolvimento:

npm run dev

A aplicação estará disponível em http://localhost:3000.
