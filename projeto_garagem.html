Categoria Full-Stack SaaS / Delivery
Cliente Garagem do Frango
Data 2026

Visão Geral do Sistema

A Garagem do Frango é uma solução completa sob medida desenvolvida para automatizar e escalonar o gerenciamento de pedidos de um restaurante especializado em frango assado e acompanhamentos. O sistema substitui o controle manual por um fluxo ágil que conecta o cliente diretamente ao painel da cozinha.

Dividido em duas grandes aplicações (frontend interativo em React e backend robusto em Node.js), o sistema conta com transmissão em tempo real de novos pedidos, otimizando o tempo de preparo e a logística de entrega.

Principais Funcionalidades

  • Cardápio Online de Alta Velocidade: Interface responsiva para o cliente final, com imagens otimizadas, seleção de variações e checkout simplificado.
  • Painel Admin em Tempo Real: Notificações instantâneas na cozinha via WebSockets (Socket.IO) sempre que um novo pedido é efetuado.
  • Gestão de Status de Pedido: Controle do fluxo produtivo (Pendente, Em Preparo, Pronto para Entrega, Finalizado).
  • Segurança & Rota Secreta: Área administrativa protegida por criptografia JWT, com controle dinâmico da rota de login para evitar acessos mal-intencionados.

Arquitetura Técnica

A arquitetura foi pensada para manter alta disponibilidade e baixo consumo de recursos, ideal para hospedagem em VPS ou servidores compartilhados otimizados:

garagem-do-frango/ ├── backend/ # Node.js + Express + MySQL + Socket.IO (Porta 3000) │ ├── database.sql # Estrutura e migração do Banco de Dados │ └── server.js # Servidor central de APIs e Sockets └── frontend/ # React + Vite + Tailwind CSS (Porta 5173 / Dist)

Como Executar Localmente

Para rodar o projeto em ambiente de desenvolvimento, siga os passos abaixo:

1. Inicializar o Banco de Dados MySQL:

mysql -u seu_usuario -p < backend/database.sql

2. Iniciar o Backend:

cd backend cp .env.example .env # Configure sua conexão MySQL e JWT_SECRET no arquivo .env npm install npm run dev

3. Iniciar o Frontend:

cd ../frontend cp .env.example .env # Defina VITE_API_URL=http://localhost:3000/api npm install npm run dev
